## PhoneMic v1.0.0

这是 **PhoneMic 独立版本线的第一个正式版本**。

从这一版起，版本编号不再沿用上游 `franj/PhoneMic` 的 0.6.x 序列，改用本项目自己的版本体系。这是一个重新出发的节点：源码已在独立的公开仓库 `StarLightInfinite/PhoneMic` 维护， README、许可证归属与致谢都已按开源项目的规范重新整理。

### 🔄 新增：手机端设置双向同步

这一版最主要的功能增量。此前手机端的配置只能由 PC 单向推送，换一台设备或清掉浏览器缓存后，设置就回到默认。现在手机端也能把设置写回 PC：

- **换机不丢设置**：PC 的 `settings.json` 是唯一真相源，握手首帧把全部配置带回手机。换设备、清缓存、重装浏览器，设置都还在。
- **手机直接改发送方式**：输入框上方的"自动 / 手动"分段控件，点一下就写回 PC。断网时先存在本地，重连后以 PC 为准自动纠正。
- **服务端严格校验**：只有白名单内的配置键能被手机写入，非法值一律拒绝并回传真实值，脏数据不会落进 `settings.json`。

功能从上游社区的实现中摘取并适配，只引入了双向同步这一块，没有带入设置页 UI 和可配快捷按钮行，保持现有界面简洁。

### 🛠 工程治理

- **持续集成**：新增 GitHub Actions，push 和 PR 自动在 Windows 环境跑全量测试（1234 条）。
- **敏感信息治理**：开发过程中产生的截图、原型、隧道地址等现场数据全部排除出仓库，公开源码不含真实内网地址、密钥或个人邮箱。
- **文档**：README 按开源标准重写，补充架构图、安全隐私说明与贡献指南；新增上游同步策略与本次功能的移植预案文档。
